欢迎来到我的小屋！

这是我用 Hugo + GitHub Pages 搭起来的个人网站，整个过程几乎没有写代码——从安装工具、选主题、调样式到发布，全都是 AI 帮的忙。

## 这个网站是怎么搭的

1. 用 Hugo（一个免费的静态网站生成器）搭建框架
2. 套用 PaperMod 主题，把配色改成了暖暖的焦糖色
3. 搭配了霞鹜文楷字体，写出来像手写的文字
4. 托管在 GitHub Pages，免费，还自动更新

## 接下来会写什么

- 生活记录
- 学习笔记
- 各种喜欢的东西

来日方长，慢慢聊。
